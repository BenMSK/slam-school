<strong>Step 1: allow reflections.</strong> A rotation is an orthogonal matrix, \(\mathbf{R}_i\T\mathbf{R}_i=\mathbf{I}_d\), with determinant \(+1\). The <strong>orthogonal group</strong> \(\operatorname{O}(d)\) keeps the first condition and drops the second, so it also contains reflections (determinant \(-1\)). Orthonormality is a set of quadratic equations in the entries, so the problem over \(\operatorname{O}(d)^n\) is a QCQP with no linear terms (the book says <em>homogeneous</em>). The map \(\operatorname{BlockDiag}_{d\times d}\) of (6.19) just reads off the \(n\) diagonal blocks of a \(dn\times dn\) matrix, and the diagonal blocks of \(\mathbf{R}\T\mathbf{R}\) are \(\mathbf{R}_i\T\mathbf{R}_i\): <span class="src">eq. (6.20) · p. 160</span>

2. Lagrangian duality for a QCQP
@@ 28
Day 2 got the lower bound by enlarging the feasible set. There is a second route to the same bound, and it is the one that produces certificates. Take the generic problem (QCQP): minimize \(\mathbf{x}\T\mathbf{C}\mathbf{x}\) subject to \(\mathbf{x}\T\mathbf{A}_i\mathbf{x}=b_i\). Introduce one number \(\lambda_i\) per constraint, a <strong>Lagrange multiplier</strong>, and form the <strong>Lagrangian</strong>
@@ 29
Two observations do all the work.
@@ 30
At any feasible \(\mathbf{x}\), the brackets are zero, so \(L(\mathbf{x},\boldsymbol{\lambda})=\mathbf{x}\T\mathbf{C}\mathbf{x}\) whatever \(\boldsymbol{\lambda}\) is.
@@ 31
Minimize \(L\) over <em>all</em> \(\mathbf{x}\), ignoring the constraints. If \(\mathbf{S}(\boldsymbol{\lambda})\succeq0\), the quadratic term is never negative and the minimum is \(\mathbf{b}\T\boldsymbol{\lambda}\), at \(\mathbf{x}=\mathbf{0}\). If \(\mathbf{S}(\boldsymbol{\lambda})\) has a direction \(\mathbf{v}\) with \(\mathbf{v}\T\mathbf{S}\mathbf{v}\lt0\), scaling \(\mathbf{x}=s\mathbf{v}\) sends \(L\) to \(-\infty\).
@@ 32
The unconstrained minimum is called the <strong>dual function</strong> \(q(\boldsymbol{\lambda})\). An unconstrained minimum is at most the value at any particular point, so for every feasible \(\mathbf{x}\): \(q(\boldsymbol{\lambda})\le L(\mathbf{x},\boldsymbol{\lambda})=\mathbf{x}\T\mathbf{C}\mathbf{x}\). Hence \(q(\boldsymbol{\lambda})\le p^\star\) for every \(\boldsymbol{\lambda}\). This is <strong>weak duality</strong>. The best such bound is the <strong>dual problem</strong>:
@@ 33
It is again an SDP, with only \(m\) unknowns. Doing the same construction on Shor's (SDP) gives the very same dual, so the two routes meet: \(\text{dual value}\le d^\star\le p^\star\). For a convex problem with a strictly feasible point (Slater's condition; here \(\mathbf{Z}=\mathbf{I}\) is one for Problem 6.3) the first inequality is an equality, which is called <strong>strong duality</strong>.
@@ 34
Example: minimize \(\mathbf{x}\T\mathbf{C}\mathbf{x}\) over unit vectors. One constraint, \(\mathbf{A}=\mathbf{I}\), \(b=1\), so \(\mathbf{S}(\lambda)=\mathbf{C}-\lambda\mathbf{I}\), which is positive semidefinite exactly when \(\lambda\) is at most the smallest eigenvalue of \(\mathbf{C}\). The dual optimum is \(\lambda_{\min}(\mathbf{C})\), the same \(-1\) that the disk picture gave for \(\mathbf{C}=\begin{bmatrix}3 &amp; 2\\ 2 &amp; 0\end{bmatrix}\) on Day 2.

The book's guarantee for when the relaxation is tight is Theorem 6.1. Let \(\bar{\mathbf{Q}}\) be the data matrix built from the true, noise-free relative poses. There is a constant \(\beta\gt0\), depending on \(\bar{\mathbf{Q}}\), such that if \(\norm{\tilde{\mathbf{Q}}-\bar{\mathbf{Q}}}_2\lt\beta\), then Problem 6.3 has a unique solution \(\mathbf{Z}^\star=\mathbf{R}^{\star\mathsf{T}}\mathbf{R}^\star\), where \(\mathbf{R}^\star\in\SO(d)^n\) is a global minimizer of Problem 6.2. <span class="src">Theorem 6.1 · p. 161</span> The norm is the spectral norm, the largest singular value, so the condition says "the noise has not moved the data matrix much". The global minimizer of the full Problem 6.1 then follows from (6.16).

Intuition: why small noise is enough
@@ 67
This is the idea, not the proof (the book refers to the SE-Sync paper for that). With perfect measurements the true rotations have cost 0, the lowest any sum of squares can go. All multipliers are zero, so \(\mathbf{S}=\bar{\mathbf{Q}}\), which is positive semidefinite: the certificate holds. For a connected graph \(\bar{\mathbf{Q}}\) has exactly \(d\) zero eigenvalues, and the rest are strictly positive. Add a little noise. The optimum and \(\mathbf{S}\) move a little. The \(d\) zeros stay at zero, because \(\mathbf{S}\hat{\mathbf{R}}\T=\mathbf{0}\) by construction, and the positive eigenvalues cannot jump below zero. So \(\mathbf{S}\) stays positive semidefinite until the noise is large enough to close that gap. You saw the pair of zeros (\(d=2\)) and the gap in the widget.
@@ 68
<strong>"A negative eigenvalue of S proves the solution is a bad local minimum."</strong> It proves only that this test cannot certify it. The solution may be suboptimal, or optimal for a problem whose relaxation is not tight.
@@ 69
<strong>"S should be positive definite."</strong> It never is: \(\mathbf{S}\hat{\mathbf{R}}\T=\mathbf{0}\) gives it at least \(d\) zero eigenvalues. The test is \(\lambda_{\min}(\mathbf{S})\ge0\), in practice "not below a small negative tolerance".
@@ 70
<strong>"The SDP optimizes over rotations."</strong> It optimizes over \(\mathbf{Z}\), a table of would-be relative rotations. Only when \(\mathbf{Z}^\star\) has rank \(d\) do actual rotations come out of it.
