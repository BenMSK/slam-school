@@ 3
After today you can project and unproject with a camera model, score a corner, match descriptors, write the reprojection cost and bundle adjustment, relate two views with the epipolar constraint, and score a trajectory.
@@ 4
Part II turns from the back-end to the front-end: how each sensor produces odometry factors, loop-closure factors, and unary factors, and how the result is scored (ATE, RPE, precision and recall). Visual SLAM is the first and reference case. A camera maps a 3D point to a pixel through a projection function \(\pi\) with calibrated intrinsics, and loses the depth on the way; depth returns only through a second view, with an uncertainty that grows as \(z^2\) and shrinks with the baseline. Feature-based systems reduce each image to keypoints (corners found with the second-moment matrix, described by vectors or bit strings, matched by distance), and estimate cameras and points by minimizing the reprojection error. Done over everything at once this is bundle adjustment; real-time systems keep it tractable with keyframes, and start it from two-view geometry.

A camera has \(f_u = f_v = 800\) and principal point \((640, 360)\). Its pose is \(\mathbf{R}^i_w = \mathbf{I}\), \(\mathbf{t}^i_w = (-1, 0, 0)\). A landmark is estimated at \(\mathbf{x}^w = (2, 1, 10)\) and was observed at pixel \((722, 437)\) with isotropic noise of standard deviation 2 pixels. Compute the point in camera coordinates, its predicted pixel, the reprojection error, and its term in (7.1).
@@ 64
Camera coordinates: \(\mathbf{x}^c = \mathbf{R}^i_w\mathbf{x}^w + \mathbf{t}^i_w = (2-1, 1, 10) = (1, 1, 10)\).
@@ 65
Prediction: \(u = 800\cdot\tfrac{1}{10} + 640 = 720\), \(v = 800\cdot\tfrac{1}{10} + 360 = 440\).
@@ 66
Error: \(\mathbf{e} = (722, 437) - (720, 440) = (2, -3)\), so \(\norm{\mathbf{e}}^2 = 13\).
@@ 67

A lens has \(k_1 = -0.3\), \(k_2 = 0.1\), no tangential distortion, \(f_u = f_v = 400\), principal point \((320, 240)\). (a) Project \(\mathbf{x}^c = (1, 1, 2)\) with and without distortion. (b) Starting from the distorted normalized coordinates, do two iterations of the fixed-point undistortion of Day 3.
@@ 69
(a) \(x' = y' = 0.5\), \(r^2 = 0.5\), \(r^4 = 0.25\). Factor: \(1 - 0.3\cdot0.5 + 0.1\cdot0.25 = 0.875\). So \(x'' = y'' = 0.4375\) and the pixel is \((400\cdot0.4375 + 320,\ 400\cdot0.4375 + 240) = (495, 415)\). Without distortion it would be \((520, 440)\): the point moved 25 pixels in each direction, about 35 pixels toward the center.
@@ 70
(b) Start at \(x' = y' = 0.4375\). Iteration 1: \(r^2 = 2\cdot0.4375^2 = 0.3828\), \(r^4 = 0.1465\), \(g = 1 - 0.1148 + 0.0147 = 0.8998\), \(x' = 0.4375/0.8998 = 0.4862\). Iteration 2: \(r^2 = 2\cdot0.4862^2 = 0.4728\), \(r^4 = 0.2235\), \(g = 1 - 0.1418 + 0.0224 = 0.8805\), \(x' = 0.4375/0.8805 = 0.4969\). The iterates approach the true value 0.5.
@@ 71
Two \(2\times2\)-pixel patches have these image gradients \((I_u, I_v)\) at their four pixels. Patch A: \((2,0), (2,0), (0,1), (0,1)\). Patch B: \((1,1), (1,1), (1,1), (1,1)\). For each, compute \(\mathbf{M}\), its eigenvalues, the Shi-Tomasi score, and the Harris response with \(k = 0.04\). Which is a corner?
@@ 72
Patch A: \(\sum I_u^2 = 4+4 = 8\), \(\sum I_v^2 = 1+1 = 2\), \(\sum I_uI_v = 0\). \(\mathbf{M} = \begin{bmatrix} 8 & 0 \\ 0 & 2 \end{bmatrix}\), eigenvalues 8 and 2. Shi-Tomasi score 2. Harris: \(16 - 0.04\cdot10^2 = 12\). Both eigenvalues are well above zero and \(R \gt 0\): a corner (gradients point in two different directions).
@@ 73
Patch B: every entry sums to 4. \(\mathbf{M} = \begin{bmatrix} 4 & 4 \\ 4 & 4 \end{bmatrix}\), eigenvalues \(4 \pm 4\), that is 8 and 0. Shi-Tomasi score 0. Harris: \(0 - 0.04\cdot8^2 = -2.56\). An edge, running diagonally: all gradients are parallel, and sliding the patch along \((1,-1)\) changes nothing. Note that the diagonal entries of \(\mathbf{M}\) alone would not reveal this; the off-diagonal entry matters.

(Stretch.) Two identical cameras have \(f = 500\), principal point \((320, 240)\), and are related by \(\mathbf{R} = \mathbf{I}\), \(\mathbf{t} = (-0.5, 0, 0)\). A keypoint is at \(\mathbf{z}_1 = (420, 190)\) in image 1. (a) Use the essential matrix to find its epipolar line in image 2. (b) The match is found at \(u_2 = 395\) on that line. Find the 3D point in camera-1 coordinates and verify it by projecting into camera 2. (c) If the disparity has standard deviation 0.5 px, how uncertain is the depth? (d) What changes if the true baseline was 1 m instead of 0.5 m?
@@ 75
(a) \(\mathbf{b}_1 = \big(\tfrac{420-320}{500}, \tfrac{190-240}{500}, 1\big) = (0.2, -0.1, 1)\). With \(\mathbf{t} = (-0.5, 0, 0)\), \(\mathbf{E} = [\mathbf{t}]_\times = \begin{bmatrix} 0 & 0 & 0 \\ 0 & 0 & 0.5 \\ 0 & -0.5 & 0 \end{bmatrix}\) and \(\mathbf{E}\mathbf{b}_1 = (0, 0.5, 0.05)\). The constraint \(\mathbf{b}_2\T\mathbf{E}\mathbf{b}_1 = 0.5\,y'_2 + 0.05 = 0\) gives \(y'_2 = -0.1\), that is \(v_2 = 500\cdot(-0.1) + 240 = 190\). The epipolar line is the row \(v = 190\).
@@ 76
(b) Disparity \(d = 420 - 395 = 25\) px, so \(z = f\,b/d = 500\cdot0.5/25 = 10\) m, and \(\mathbf{x}^1 = 10\,\mathbf{b}_1 = (2, -1, 10)\). Check: \(\mathbf{x}^2 = \mathbf{x}^1 + \mathbf{t} = (1.5, -1, 10)\), which projects to \(u = 500\cdot0.15 + 320 = 395\), \(v = 500\cdot(-0.1) + 240 = 190\). It matches.
@@ 77
(d) The pixels are the same, so the rays are the same; \(z = 500\cdot1/25 = 20\) m and the point becomes \((4, -2, 20)\). Everything doubles. The images alone cannot tell the two cases apart, which is the monocular scale ambiguity. A stereo rig, where \(b\) is calibrated, or an IMU resolves it.
