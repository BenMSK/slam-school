2. The dual quadric: describe the surface by its tangent planes
@@ 15
The book switches to the <strong>dual</strong> description: the set of planes that touch the ellipsoid.
@@ 16
with \(\mathbf{Q}^*_{\mathbf{s}}\) the adjugate of \(\mathbf{Q}_{\mathbf{s}}\). A quadric does not change when its matrix is multiplied by a constant, so the adjugate \(\det(\mathbf{Q}_{\mathbf{s}})\mathbf{Q}_{\mathbf{s}}^{-1}\) can be replaced by \(\mathbf{Q}_{\mathbf{s}}^{-1} = \diag(s_1^2, s_2^2, s_3^2, -1)\). An image outline is made of rays that touch the object, so the tangent description is the one a camera sees. <span class="src">§16.2.1.2 · pp. 459–460</span>
@@ 17
Filling the gap: why \(\mathbf{Q}^* = \mathbf{Q}^{-1}\), and why duals are easy to project
@@ 18
<strong>Tangent planes.</strong> Write a plane as \(\{\mathbf{x} : \mathbf{y}\T\mathbf{x} + 1 = 0\}\), which is the homogeneous vector \([\mathbf{y}; 1]\). Every point of the ellipsoid is \(\mathbf{x} = \diag(\mathbf{s})\,\mathbf{u}\) with \(\norm{\mathbf{u}} \le 1\). Then \(\mathbf{y}\T\mathbf{x} = (\diag(\mathbf{s})\mathbf{y})\T\mathbf{u}\), and as \(\mathbf{u}\) runs over the unit ball this takes every value between \(-\norm{\diag(\mathbf{s})\mathbf{y}}\) and \(+\norm{\diag(\mathbf{s})\mathbf{y}}\). The plane needs the value \(-1\). It misses the ellipsoid if \(\norm{\diag(\mathbf{s})\mathbf{y}} \lt 1\), cuts through it if \(\gt 1\), and touches it at one point exactly when
@@ 19
The matrix in the middle is \(\mathbf{Q}_{\mathbf{s}}^{-1}\), and the tangent planes are the boundary of the set in (16.6).
@@ 20
<strong>Moving the object.</strong> If points move by a \(4\times4\) matrix \(\mathbf{H}\) (\(\mathbf{x}' = \mathbf{H}\mathbf{x}\)), a plane \(\boldsymbol{\pi}\) moves to \(\boldsymbol{\pi}' = \mathbf{H}^{-\top}\boldsymbol{\pi}\), since then \(\boldsymbol{\pi}'^{\top}\mathbf{x}' = \boldsymbol{\pi}\T\mathbf{H}^{-1}\mathbf{H}\mathbf{x} = 0\) still holds. Substituting \(\boldsymbol{\pi} = \mathbf{H}\T\boldsymbol{\pi}'\) into \(\boldsymbol{\pi}\T\mathbf{Q}^*\boldsymbol{\pi} = 0\) gives \(\boldsymbol{\pi}'^{\top}(\mathbf{H}\mathbf{Q}^*\mathbf{H}\T)\boldsymbol{\pi}' = 0\): the dual moves as \(\mathbf{H}\mathbf{Q}^*\mathbf{H}\T\), with no inverse.
@@ 21
<strong>Projecting.</strong> An image line \(\mathbf{l}\) and the camera centre span a plane, \(\boldsymbol{\pi} = \mathbf{M}\T\mathbf{l}\), where \(\mathbf{M}\) is the \(3\times4\) camera matrix. The line touches the object's outline exactly when that plane touches the object: \(\mathbf{l}\T(\mathbf{M}\mathbf{Q}^*\mathbf{M}\T)\mathbf{l} = 0\). So the outline is the conic whose dual is \(\mathbf{M}\mathbf{Q}^*\mathbf{M}\T\). The point form \(\mathbf{Q}\) would need the inverse of \(\mathbf{M}\), which a \(3\times4\) matrix does not have.

4. A mesh, compared with a segmentation mask
@@ 32
A triangle <strong>mesh</strong> with vertices \(\mathcal{V} = \{\mathbf{s}_j\}_j\) and faces \(\mathcal{F}\) can follow the real surface. It is compared with a <strong>segmentation mask</strong> \(\mathbf{z}_i \subset \R^2\), the set of pixels the detector assigns to the object. A <strong>rasterization function</strong> \(\rho(\mathcal{V}, \mathcal{F})\) fills in the pixels the mesh covers once its vertices are projected as in (16.3). Call that rendered set \(\hat{\mathbf{z}}_i = \rho(\{\pi(\mathbf{q}_i^{-1}\mathbf{T}_i, \lambda_i\mathbf{s}_{i,j})\}_j, \mathcal{F})\). The residual is the reciprocal of the intersection-over-union: <span class="src">§16.2.1.3 · pp. 461–462</span>
@@ 33
If the rendering covers 500 pixels, the mask 400, and they share 300, the union is \(500 + 400 - 300 = 600\) and \(r = 600/300 = 2\). A perfect match gives the minimum, \(r = 1\).
@@ 34
The catch is the gradient. A pixel is either covered or not, so \(\rho\) is piecewise constant in the vertex positions and its derivative is zero almost everywhere. <strong>Differentiable rendering</strong> replaces it with an approximate gradient, as in <a href="#d115">Week 20 · Day 1</a>. The vertices can be optimized directly or through the coefficients of (16.2). <span class="src">§16.2.1.3 · pp. 461–462</span>

5. Implicit shapes: a function instead of a surface
@@ 36
The models so far are explicit: they list the surface. An <strong>implicit</strong> model is a function of space whose level set is the surface: an <strong>occupancy function</strong>, \(-1\) inside the object \(\mathcal{S}\) and \(+1\) outside (16.13), or a <strong>signed distance function</strong>, <span class="src">§16.2.1.4 · pp. 464–465</span>
@@ 37
For a unit sphere, \(d_{\mathcal{S}}(\mathbf{x}) = \norm{\mathbf{x}} - 1\): \(-0.5\) at \((0.5, 0, 0)\) and \(2\) at \((3, 0, 0)\). You met SDFs as maps in <a href="#d44">Week 8 · Day 2</a>. Here one SDF describes one object, and a network \(d_\theta(\mathbf{x}, \mathbf{s})\) produces it: a decoder with weights \(\theta\) shared by a whole category, and a <strong>shape code</strong> \(\mathbf{s} \in \R^d\) that selects one shape within it.
@@ 38
A depth sensor at pose \(\mathbf{T}_i\) gives points \(\mathbf{y}_{i,j}\) near the object with measured distances \(z_{i,j}\) to its surface. The residual asks the decoder for the distance at each point: <span class="src">§16.2.1.4 · p. 465</span>
@@ 39
The argument of \(d_\theta\) takes the point from the robot frame to the world, then to the object frame, then divides by \(\lambda_i\), so the decoder is always queried in its canonical frame. Trust that description in words: with yesterday's conventions for \(\mathbf{T}\) and \(\mathbf{q}\) the same chain reads \(\lambda^{-1}\mathbf{q}^{-1}\mathbf{T}\mathbf{y}\).
@@ 40
<strong>Training</strong>, offline and once per category, holds the poses and scales fixed and optimizes \(\theta\) with one code per training object. <strong>Testing</strong>, online inside SLAM, freezes \(\theta\) and optimizes \(\mathbf{T}_i\), \(\mathbf{q}_i\), \(\lambda_i\), \(\mathbf{s}_i\) for an object never seen before. <span class="src">§16.2.1.4 · p. 466</span>
