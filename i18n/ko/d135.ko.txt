@@ 28
<strong>Unrolling.</strong> 한 점을 \(c_k = 0\)에서 시작해, 가중치 \(\alpha_1, \dots, \alpha_n\)으로 feature \(\mathbf{f}_1, \dots, \mathbf{f}_n\)을 넣습니다. 주장: \(n\)번 갱신한 뒤 \(c_k = \sum_t \alpha_t\)이고 \(c_k \mathbf{f}_k = \sum_t \alpha_t \mathbf{f}_t\)입니다. 한 번 갱신한 뒤에는 성립합니다. \(n-1\)번 뒤에 성립한다면, (17.2)에 분모를 곱하면 \(c_k^{\text{new}} \mathbf{f}_k^{\text{new}} = c_k \mathbf{f}_k + \alpha_n \mathbf{f}_n = \sum_{t \le n} \alpha_t \mathbf{f}_t\)가 됩니다. 따라서
@@ 29
map은 개별 view를 저장하지 않고, 이 누적 가중 평균과 가중치의 합만 저장합니다. <a href="#d44">8주차 · Day 2</a>의 TSDF weight와 같은 요령입니다.
@@ 30
<strong>왜 평균하는가.</strong> 각 view의 feature를 실제 feature에 독립 오차를 더한 것, \(\mathbf{f}_t = \mathbf{f} + \mathbf{e}_t\)로 모델링하고, \(\mathbf{e}_t\)의 \(d\)개 성분이 각각 분산 \(s^2\)를 가진다고 합시다. 가중치가 같으면 평균의 오차는 성분당 분산이 \(s^2/n\)이므로, 그 제곱 길이는 약 \(d s^2 / n\)입니다. 이 오차는 대부분 \(\mathbf{f}\)(길이 1)에 수직이므로

5. object마다 feature 하나
@@ 41
dense feature map은 vector가 커서 규모를 키우기 어렵습니다. 세어 봅시다. 점 100만 개가 각각 768개 숫자로 된 feature(책이 p. 510에서 한 CLIP 모델에 대해 인용하는 크기)를 숫자당 4 byte로 가지면 약 3 GB입니다. 가까운 점들은 대개 같은 물체에 속하고 semantics를 공유하므로, feature를 object마다 한 번만 저장합니다. <span class="src">§17.3.2 · p. 504</span> object 200개에는 200 × 768 × 4 byte, 약 0.6 MB가 필요합니다.
@@ 42
<strong>object map</strong>은 집합 \(\mathsf{V}_O = \{o_j\}_{j=1}^{J}\)입니다. 각 object에는 point cloud \(\mathsf{P}_{o_j}\), feature \(\mathbf{f}_{o_j}\), detection 횟수 \(n_{o_j}\)가 있습니다. 새 frame마다 다음을 합니다: <span class="src">§17.3.2 · pp. 504–505</span>
@@ 43
<strong>추출.</strong> \(\texttt{Seg}(\mathbf{I})\)의 각 mask에 대해 crop을 encode해서 \(\mathbf{f}^M_i\)를 얻고, 그 픽셀들을 back-project해서 map frame의 point cloud \(\mathsf{P}^M_i\)를 만듭니다.
@@ 44
<strong>Association.</strong> 각 mask를 기존 object들과 비교합니다. geometric similarity \(\phi_{geo} \in [0,1]\)은 mask 점 중 object의 cloud 안에서 거리 \(\delta_{nn}\) 이내에 이웃이 있는 점의 비율입니다. semantic similarity는 \(\phi_{sim} = \tfrac{1}{2}(\langle \mathbf{f}_i, \mathbf{f}_{o_j} \rangle + 1) \in [0,1]\)입니다. 둘을 합치거나 각각에 threshold를 적용합니다. 매칭되지 않은 mask는 새 object를 시작합니다.
@@ 45
<strong>Fusion.</strong> 매칭되면 \(\mathbf{f}_{o_j} \leftarrow (n_{o_j}\mathbf{f}_{o_j} + \mathbf{f}_i)/(n_{o_j}+1)\), \(\mathsf{P}_{o_j} \leftarrow \mathsf{P}_{o_j} \cup \mathsf{P}^M_i\), \(n_{o_j} \leftarrow n_{o_j}+1\)입니다. \(\alpha = 1\)이고 횟수를 confidence로 쓴 (17.2)입니다.
@@ 46
<strong>정돈.</strong> 가끔 중복된 object를 병합하고, 횟수가 적은 object는 버립니다.
@@ 47
<strong>숫자로 보기.</strong> mask cloud에 점이 200개 있고, 그중 150개가 \(\delta_{nn}\) 이내에 object 점을 가지므로 \(\phi_{geo} = 0.75\)입니다. feature의 내적은 0.6이므로 \(\phi_{sim} = 0.8\)입니다. 둘 다 threshold를 통과하고 object가 \(n = 4\)였다면, 그 feature는 \((4\mathbf{f}_o + \mathbf{f}_i)/5\)가 되고 \(n = 5\)가 됩니다.
@@ 48
