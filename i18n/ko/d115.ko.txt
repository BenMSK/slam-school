1. 저장된 geometry에서 학습된 함수로
@@ 12
<a href="#d44">8주차 · Day 2</a>의 map은 geometry를 직접 저장합니다: point들, 또는 occupancy 값의 grid입니다. 딥러닝이 이미지에서 3D로 넘어갔을 때, 첫 시도들은 이 구조를 그대로 network에 넣었습니다. 책은 문제를 이렇게 짚습니다: 이 구조들은 이산적이고, 임의 모양의 닫힌 연속 표면을 간결하게 기술하기 어려우며, 이것이 gradient 기반 최적화를 방해합니다. <span class="src">§14.1.1 · p. 398</span>
@@ 13
대안은 모양이 <em>함수 자체가 되게</em> 하는 것입니다. <strong>multi-layer perceptron (MLP)</strong>은 작은 neural network입니다: 여러 층을 쌓은 것으로, 각 층은 입력에 행렬을 곱하고, 벡터를 더하고, 간단한 비선형 함수를 적용합니다. 그 행렬과 벡터가 <strong>weights</strong>(가중치)입니다. 3D 좌표를 넣고 숫자 하나를 내도록 학습시킵니다: <strong>occupancy</strong>(점유: 이 점이 무언가의 안쪽인가?), 또는 <strong>signed distance function (SDF)</strong>(부호 거리 함수), 즉 가장 가까운 표면까지의 거리에 안쪽인지 바깥쪽인지 알려 주는 부호를 붙인 값입니다. 표면은 SDF가 0인 점들의 집합입니다. DeepSDF는 8층 MLP로 정확히 이렇게 하며, 어떤 모양을 뜻하는지 고르는 추가 입력 벡터(latent code)를 선택적으로 받습니다. <span class="src">§14.1.1 · p. 398 · Fig. 14.1</span>
@@ 14
이런 network가 학습해야 하는 것을 손으로 써 본 예: 원점이 중심이고 반지름이 1인 구에 대해 \(f(\mathbf{x}) = \norm{\mathbf{x}} - 1\)입니다. 그러면 \(f(0.5, 0, 0) = -0.5\) (안쪽), \(f(2, 0, 0) = 1\) (바깥쪽), \(f(0.6, 0.8, 0) = 0\) (표면 위)입니다. 학습된 MLP는 공식이 없는 모양에 대해 \(f\)의 역할을 합니다.

@@ 49

@@ 50

@@ 51
숫자로: \(c = 0.9\), \(b = 0.1\), \(\alpha = 0.5\)이면 \(C = 0.5\)입니다. 사진은 \(C_{gt} = 0.7\)이므로 \(L = 0.04\)이고 \(\partial L/\partial\alpha = 2(-0.2)(0.8) = -0.32\)입니다. 크기 0.5의 gradient descent step은 \(\alpha\)를 \(0.5 + 0.5 \times 0.32 = 0.66\)으로 옮깁니다. 이제 \(C = 0.66 \times 0.9 + 0.34 \times 0.1 = 0.628\)이고 \(L = 0.0052\)입니다: 사진이 rendering 결과보다 밝았기 때문에 blob이 더 불투명해졌습니다. 실제 시스템은 수백만 개의 parameter와 픽셀에 대해 같은 일을 하며, 미분은 automatic differentiation이 만들어 냅니다 (<a href="#d37">7주차 · Day 1</a>).
@@ 52

빈틈 채우기: "표면을 찾기 전의 gradient"가 왜 중요한가
@@ 67
한 ray 위에 샘플 두 개를 놓습니다. opacity는 \(\alpha_1, \alpha_2\), 밝기는 \(c_1, c_2\)이고 배경은 검은색입니다. 샘플 2의 빛은 샘플 1을 지나야 하므로
@@ 68
현재 scene이 틀렸다고 합시다: 샘플 1은 비어 있고 (\(\alpha_1 = 0\)) 샘플 2는 꽉 찬 어두운 벽입니다 (\(\alpha_2 = 1\), \(c_2 = 0.2\)). 그래서 \(C = 0.2\)입니다. 사진에는 밝은 물체가 보여 \(C_{gt} = 0.8\)이고, 샘플 1의 색은 \(c_1 = 0.8\)입니다. 그러면 \(\partial C/\partial\alpha_1 = 0.8 - 0.2 = 0.6\)이고 \(\partial L/\partial\alpha_1 = 2(0.2 - 0.8)(0.6) = -0.72\)입니다. 아직 아무것도 없는데도 미분은 0이 아닙니다: loss가 빈 점에 물질을 요구하는 것입니다.
@@ 69
단단한 표면은 이런 신호를 주지 않습니다. 픽셀이 불투명한 표면을 본다면, 그 표면을 ray를 따라 살짝 밀어도 픽셀은 전혀 바뀌지 않으므로, 표면 위치에 대한 미분은 0입니다. 예외는 픽셀 값이 갑자기 바뀌는 물체 윤곽뿐입니다. 그래서 mesh 기반 방법은 rasterizer를 부드럽게 만들어야 했고, volume은 최적화하기가 더 쉽습니다.

4. NeRF와 3DGS 한눈에 보기
@@ 71
<strong>NeRF</strong> (2020)는 scene을 MLP 하나에 저장하고 ray marching으로 rendering합니다: 픽셀마다 ray를 따라 나아가며 각 샘플에서 MLP에 opacity와 색을 묻습니다. MLP는 3D 위치와 보는 방향을 입력으로 받는데, 세밀한 디테일을 표현할 수 있도록 입력이 positional encoding을 거칩니다. NeRF는 <strong>posed</strong> 컬러 이미지(카메라 pose를 이미 아는 이미지)로 rendering loss를 최소화하여 학습하며, 고품질 <strong>novel view synthesis</strong>를 만들어 냅니다: 한 번도 촬영하지 않은 시점에서 본 이미지입니다. <span class="src">§14.1.3 · pp. 399–400</span>
@@ 72
NeRF의 병목은 학습 속도입니다. 이후 연구는 MLP를 명시적인 volume 구조, 즉 voxel grid와 hash table로 대체하거나 보조했고, MLP 없이도 비슷한 품질에 도달했습니다. 책은 여기서 핵심 요소가 network가 아니라 differentiable volume rendering이라는 교훈을 끌어냅니다. 그래도 픽셀마다 ray를 따라 나아가는 방식은 여전히 rendering이 느립니다. <span class="src">§14.1.3 · p. 400</span>
@@ 73
<strong>3D Gaussian splatting</strong> (2023)은 반투명한 물질이라는 아이디어는 유지하되 저장 방식과 renderer를 모두 바꿉니다. scene은 반투명 Gaussian blob의 큰 집합이고, alpha blending으로 섞이며, differentiable rasterization으로 rendering됩니다: NeRF가 ray를 순회하는 자리에서, 이 renderer는 blob을 순회하며 각각을 이미지에 투영합니다. scene의 대부분은 비어 있으므로 rendering이 훨씬 빠르고, 학습 속도는 가장 빠른 volumetric NeRF 변형들과 비슷합니다. <span class="src">§14.1.3 · p. 401</span>
