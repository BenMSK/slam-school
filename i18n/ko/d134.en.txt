1. A feature is a vector, and similarity is an angle
@@ 12
A <strong>feature</strong> (also called an embedding, representation, or code) is the real-valued vector a deep network outputs for one input. The book hides the network behind a function: an <strong>encoder</strong> \(f_{\mathcal{X}}\) for inputs of modality \(\mathcal{X}\) (text, image, sound) maps an input \(x\) to a \(d\)-dimensional feature \(\mathbf{f}_x = f_{\mathcal{X}}(x) \in \R^d\). The property that matters is that distances in feature space measure meaningful similarity, so that "how similar is this caption to this image?" becomes a calculation. <span class="src">§17.2.1 · p. 496</span>
@@ 13
The standard measure is <strong>cosine similarity</strong>, the cosine of the angle between two features drawn as arrows from the origin: <span class="src">§17.2.1 · p. 496</span>
@@ 14
<strong>Numbers.</strong> \(\mathbf{a} = (3, 4)\), \(\mathbf{b} = (4, 3)\): \(\langle \mathbf{a}, \mathbf{b} \rangle = 12 + 12 = 24\), both norms are 5, so \(\cos\theta = 24/25 = 0.96\), an angle of about 16°. It ranges from 1 (same direction) through 0 (perpendicular, unrelated) to −1 (opposite), and ignores length.

4. Generative models: one token at a time
@@ 52
A <strong>large language model (LLM)</strong> is a transformer trained to generate text. Text is first cut into <strong>tokens</strong> (words, sub-words, characters, or bytes from a fixed vocabulary), each with a learnable embedding. The training objective is <strong>next-token prediction</strong>: given the first \(T-1\) tokens, output the probabilities \(p(w_T \mid w_{1:T-1})\) of the next one. <span class="src">§17.2.2 · p. 498</span>

@@ 56
Each new token costs one pass through a very large network. Compare CLIP: one pass per image, then dot products. This is the book's remark that generative inference "tends to be more computationally expensive than extracting features". <span class="src">§17.2 · p. 495</span>
@@ 57
An LLM can be applied to any task whose instructions, inputs, and outputs fit in text, and the wording of the prompt matters. The book names two prompt techniques: <strong>chain-of-thought</strong> (ask the model to reason step by step) and <strong>in-context learning</strong> (put input–output examples in the prompt). <span class="src">§17.2.2 · p. 498</span> A <strong>vision language model (VLM)</strong> is an LLM that also accepts image tokens. The book's example, LLaVA, connects the CLIP vision encoder to an LLM and trains on vision-and-language data. Given the right prompt a VLM can classify, caption, or answer questions about an image. <span class="src">§17.2.2 · p. 499</span> As of the book's April 2026 edition it lists the LLaMa family and the GPT models as widely used, and notes that newer models appear frequently.

5. Masks without names
@@ 59
The third tool answers "which pixels belong together?" For an RGB image \(\mathbf{I}\) of width \(W\) and height \(H\), a segmenter returns a set of binary masks \(\mathbf{Z}_i \in \{0,1\}^{H \times W}\), one per likely object: \(\mathbf{Z}_i[u,v] = 1\) where pixel \((u,v)\) belongs to region \(i\). The book writes this function \(\texttt{Seg}(\cdot)\). The masks must be <strong>class-agnostic</strong>, meaning proposed without any class list, or the segmenter would bring the closed set back in. <span class="src">§17.2.3 · p. 499</span>
@@ 60
The main tool is the Segment Anything Model (SAM). It is <strong>promptable</strong>: give it pixel coordinates, a bounding box, or another mask, and it predicts a mask. It can also process a whole image and return masks for the instances in it. Unlike the models above, SAM is trained by large-scale <em>supervised</em> learning. It can also refine the boxes of an open-vocabulary detector, which gives better object outlines and shorter inference time. <span class="src">§17.2.3 · p. 499</span>
@@ 61
<strong>"CLIP gives a language-aligned feature for every pixel."</strong> Its aligned feature describes the whole image. Patch features can be extracted, but the book warns not to expect them to be language-aligned.
@@ 62
<strong>"A higher dot product always means more similar."</strong> Only for unit vectors. Without normalizing, a long vector wins by length alone.

Q1. What is the cosine similarity of a = (1, 2, 2) and b = (2, 1, 2)?
@@ 64
The inner product is 2 + 2 + 4 = 8 and both norms are √9 = 3, so the cosine is 8/9 = 0.89.

Q3. Two unit features are at squared Euclidean distance 0.5. What is their cosine similarity?
@@ 72
For unit vectors the squared distance is 2 − 2·cos, so cos = (2 − 0.5)/2 = 0.75.
