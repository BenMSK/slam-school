Before asking how accurate an estimator is, ask whether the measurements can determine the state at all. If two different states produce exactly the same measurements, no algorithm can tell them apart. For a linearized system this becomes a question about one matrix: a direction \(\mathbf{u}\) in state space is <strong>unobservable</strong> when moving the initial state along \(\mathbf{u}\) changes none of the predicted measurements.

@@ 13

@@ 20
The book goes straight to the full inertial system. The idea is easier to see on a small linear one first. This section is background that the book assumes.
@@ 21

@@ 22
Everything the sensors will ever report is a function of the initial state \(\mathbf{x}_1\), because \(\mathbf{x}_k = \boldsymbol{\Phi}^{k-1}\mathbf{x}_1 + (\text{known})\). Stack the first \(K\) measurements:
@@ 23
\(\mathbf{M}\) is the <strong>observability matrix</strong>. Two initial states \(\mathbf{x}_1\) and \(\mathbf{x}_1 + \mathbf{u}\) give identical measurements exactly when \(\mathbf{M}\mathbf{u} = \mathbf{0}\). The set of such \(\mathbf{u}\) is the <strong>nullspace</strong> of \(\mathbf{M}\). So:
@@ 24
If \(\rank \mathbf{M} = n\), the nullspace holds only \(\mathbf{0}\), and \(\mathbf{x}_1\) (hence every later state) can be recovered. The system is <strong>observable</strong>.
@@ 25
If \(\rank \mathbf{M} = n - d\), there are \(d\) independent unobservable directions (the rank–nullity theorem).
@@ 26

5. From \(\mathbf{F}\) to the transition matrix \(\boldsymbol{\Phi}\)
@@ 57
Estimators run in discrete time, so we need the matrix that carries an error from time \(t_k\) to \(t_{k+1}\) when there is no noise: \(\tilde{\mathbf{x}}_{k+1} = \boldsymbol{\Phi}_{(k+1,k)}\,\tilde{\mathbf{x}}_k\). This <strong>state transition matrix</strong> solves \(\dot{\boldsymbol{\Phi}} = \mathbf{F}\boldsymbol{\Phi}\) starting from the identity. <span class="src">§11.3.1.1 · pp. 321–322</span> Transition matrices chain: \(\boldsymbol{\Phi}_{(k,1)} = \boldsymbol{\Phi}_{(k,k-1)}\cdots\boldsymbol{\Phi}_{(2,1)}\).

@@ 62
Three things to read off:
@@ 63
<strong>Rows 2, 4, 6 are identity rows.</strong> Without noise, bias errors and feature errors do not change.
@@ 64
<strong>Row 5 is full.</strong> A position error at \(t_{k+1}\) collects contributions from every IMU error: tilt, both biases, velocity.
@@ 65
<strong>Column 5 holds only one identity block.</strong> A position error at \(t_k\) is copied to \(t_{k+1}\) and feeds nothing else. The IMU does not care where it is. Keep this in mind for Day 3: it is the first hint that global position will be unobservable.
@@ 66
<strong>"Unobservable means the estimator is broken."</strong> It means some combination of the unknowns cannot be determined from this data. Often that combination is a harmless choice of reference frame (Day 3).
@@ 67
<strong>"Observability depends on how noisy the sensors are."</strong> It is a property of the noise-free model: which changes of state alter the predicted measurements. Noise decides how well the observable part is estimated.
@@ 68
<strong>"The rotation error has nine entries."</strong> \(\tilde{\boldsymbol{\theta}}\) is a 3-vector in the tangent space, so the IMU error state has \(5 \times 3 = 15\) entries.
