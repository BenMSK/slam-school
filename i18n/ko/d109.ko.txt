빈틈 채우기: 다섯 줄로 보는 network, loss, training
@@ 84
<strong>neural network</strong>(신경망)는 <strong>layer</strong>(층)라 부르는 간단한 미분 가능한 단계들을 합성해 만든 함수 \(f_\theta\)입니다. 벡터 \(\theta\)는 조정할 수 있는 모든 수, 곧 <strong>parameter</strong> 또는 가중치를 담습니다. <strong>loss</strong>(손실) \(\mathcal{L}(\theta)\)는 training 예제 집합에서 출력이 원하는 값과 얼마나 다른지를 잽니다. <strong>training</strong>(학습)은 gradient descent로 loss를 낮춥니다:
@@ 85
여기서 step size \(\eta\)는 작은 값입니다. <a href="#d10">2주차 · Day 4</a>의 steepest descent를 로봇의 state 대신 가중치에 적용한 것입니다. parameter가 하나인 예: \(\mathcal{L}(\theta) = (\theta - 3)^2\), 시작점 \(\theta = 0\), \(\eta = 0.25\). gradient는 \(2(\theta - 3) = -6\)이므로 \(\theta\)는 \(0 - 0.25 \cdot (-6) = 1.5\)가 됩니다. 다음 gradient는 \(-3\)이고, \(\theta = 2.25\)가 됩니다. step마다 최솟값 3까지의 거리가 절반으로 줄어듭니다.
@@ 86
gradient는 reverse-mode automatic differentiation(<a href="#d37">7주차 · Day 1</a>)으로 계산합니다. 그래서 모든 layer가 미분 가능해야 합니다. label이 센서나 simulator에서 온다면(예: 실제 depth) training은 <strong>supervised</strong>(지도 학습)입니다. loss를 입력 데이터만으로 만든다면 <strong>self-supervised</strong>(자기 지도 학습)입니다. 내일 그런 예를 하나 만납니다.
@@ 87
이번 주 내내 두 종류의 layer가 나옵니다.
@@ 88
<strong>convolutional</strong>(합성곱) layer는 작은 filter 하나를 이미지 위로 밀면서 모든 위치에 적용합니다. 1-D filter \((-1, 0, 1)\)과 신호 \((2, 2, 5, 9, 9)\)에서 안쪽 세 출력은 \(5 - 2 = 3\), \(9 - 2 = 7\), \(9 - 5 = 4\)입니다. filter는 밝기가 바뀌는 곳에서 반응합니다. <strong>convolutional neural network (CNN)</strong>은 학습된 filter를 가진 이런 layer를 여러 겹 쌓고, 보통 진행하면서 이미지 격자를 줄입니다. 그래서 출력은 <strong>feature vector</strong>의 거친 격자가 됩니다. RAFT의 encoder는 입력 해상도의 1/8에서 feature를 출력합니다. <span class="src">§13.2.3 · p. 376</span>
@@ 89
<strong>attention</strong> layer는 모든 feature vector가 나머지 전부를 보게 합니다. 이미지에서 얼마나 멀리 떨어져 있든 상관없습니다. <strong>transformer</strong>는 주로 attention layer로 이루어진 network이고, <strong>vision transformer (ViT)</strong>는 작은 이미지 patch를 <strong>token</strong>이라는 벡터로 바꾸어 입력으로 받는 transformer입니다. Figure 13.6은 attention을 MatMul, SoftMax, MatMul의 세 상자로 그립니다. <span class="src">Fig. 13.6 · p. 375</span>
@@ 90
빈틈 채우기: MatMul → SoftMax → MatMul이 계산하는 것
@@ 91
<strong>query</strong> 벡터 \(\mathbf{q}\) 하나와, 각각 <strong>key</strong> \(\mathbf{k}_j\)와 <strong>value</strong> \(\mathbf{v}_j\)를 내놓는 token 집합을 생각합니다.
@@ 92
첫 번째 행렬 곱은 모든 score \(s_j\)를 한 번에 계산합니다. <strong>softmax</strong>는 score를 합이 1인 양의 가중치로 바꿉니다. 두 번째 행렬 곱은 그 가중치로 value를 평균합니다. (transformer는 score를 벡터 길이의 제곱근 \(\sqrt{d}\)로 나누기도 하고, query, key, value를 만드는 linear map도 학습합니다.)
@@ 93
예: score \((2, 1, 0)\)에서 \(e^2 = 7.39\), \(e^1 = 2.72\), \(e^0 = 1\)이고, 합은 11.11입니다. 가중치는 \(0.665, 0.245, 0.090\)입니다. value가 수 \(10, 20, 30\)이라면 출력은 \(6.65 + 4.90 + 2.70 = 14.25\)입니다.
@@ 94
<strong>self-attention</strong>에서는 query와 key가 같은 이미지에서 나옵니다. <strong>cross-attention</strong>에서는 query가 한 이미지에서, key와 value는 다른 이미지에서 나옵니다. network는 이렇게 두 view를 비교합니다.
@@ 95
직접 해 보기: query를 돌린 다음 선명도 β를 높여 보십시오.
@@ 96
눈여겨볼 점: 처음에는 query가 key k2를 거의 정면으로 가리키므로 k2가 가중치 0.73을 받고, 출력 2.15가 value 2 쪽으로 끌려갑니다. β = 0이면 모든 key가 1/6을 받고 출력은 단순 평균 3.5입니다. β = 20이면 layer가 k2 하나만 고릅니다. attention은 "가장 잘 맞는 것을 찾아라"를 부드럽고 미분 가능하게 말하는 방법입니다.
@@ 97
<strong>"Part III가 Part I, II를 대체한다."</strong> 이 장의 시스템도 여전히 factor graph 위에서 least-squares 문제를 풉니다. 바뀌는 것은 residual과 그 가중치가 어디서 오느냐입니다.
@@ 98
<strong>"큰 image-language model이 있으면 map은 필요 없다."</strong> Prelude는 이런 모델이 공간 이해에 자주 어려움을 겪고, 많은 작업에 지속적인 3D 표현이 필요하다고 말합니다. <span class="src">§III.2 · p. 362</span>
@@ 99
<strong>"학습된 구성 요소는 언제나 도움이 된다."</strong> 따로 학습한 모듈을 이어 붙이면 오차가 누적됩니다. 바로 이 관찰이 end-to-end training의 이유입니다. <span class="src">p. 366</span>
