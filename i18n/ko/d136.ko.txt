<a href="#d116">20주차</a>의 radiance field도 언어를 담을 수 있습니다. <strong>LERF</strong>는 NeRF에 두 번째 출력, 즉 점 \(\mathbf{x}\)와 scale \(s\)에서의 semantic embedding을 줍니다. 이 embedding은 색과 같은 방식으로 ray를 따라 rendering되며, 여러 scale의 이미지 crop에 대한 CLIP embedding으로 학습합니다. query할 때는 rendering된 각 embedding의 유사도를 <strong>relevancy score</strong>로 바꿉니다: <span class="src">§17.3.3 · p. 510</span>

빈틈 채우기: (17.7)이 계산하는 것
@@ 35
텍스트와의 유사도를 \(a\), canonical phrase \(i\)와의 유사도를 \(b_i\)라고 씁니다. 분자와 분모를 \(e^{a}\)로 나누면 \(1/(1 + e^{\,b_i - a})\)가 되고, 이 값은 \(a - b_i\)가 클수록 커집니다. 따라서 최솟값은 가장 큰 \(b_i\)가 정합니다. 점수는 \(1/(1 + e^{\,b_{\max} - a})\)이고, query가 모든 일반 문구를 이길 때 정확히 0.5를 넘습니다. 날것의 cosine은 이것을 말해 줄 수 없습니다. "object"는 모든 것과 어느 정도 비슷하기 때문입니다.
@@ 36
<strong>숫자로 보기.</strong> \(a = 0.30\)이고 \(b = 0.20, 0.25, 0.10, 0.28\)이면 점수는 \(1/(1 + e^{-0.02}) = 0.505\)입니다. \(a = 0.22\)이면 \(1/(1 + e^{0.06}) = 0.485\)입니다. 이 점은 query보다 일반 문구에 더 가까워 보입니다.
@@ 37
<strong>LangSplat</strong>은 splat map의 Gaussian에 language feature를 붙이며, 세 단계 granularity의 SAM segment에 대한 CLIP vector를 씁니다. Gaussian마다 512개 숫자로 된 vector는 메모리가 너무 많이 들므로, 각 vector를 숫자 3개로 압축하는 scene 전용 network와 이를 복원하는 decoder를 학습합니다. scene 하나는 CLIP의 학습 corpus보다 훨씬 덜 다양하므로 숫자 3개로 충분합니다. <span class="src">§17.3.3 · pp. 510–511</span>

4. 무엇이 object인지는 task가 정한다
@@ 39
class 목록이 없다면 무엇이 object 하나일까요? 책의 피아노는 task가 옮기기라면 object 하나이고, 연주하기라면 90개가 넘으며(건반과 페달), 조율하기라면 수백 개입니다. <span class="src">§17.3.4 · pp. 511–512</span> <strong>Clio</strong>는 문제를 이렇게 세웁니다. "배낭 청소하기", "소스 봉지 가져오기" 같은 자연어 task가 주어지면, task에 필요한 granularity의 object로 된 map을 만듭니다. Clio는 <strong>Information Bottleneck</strong>을 씁니다. \(X\)를 잘게 나뉜 primitive(over-segmentation한 3D 조각), \(\tilde{X}\)를 cluster, \(Y\)를 task라고 합시다. 다음 문제를 푸는 할당 \(p(\tilde{x} \mid x)\)를 찾습니다: <span class="src">§17.3.4 · p. 512</span>

@@ 42
두 변수가 독립이면 0입니다. (17.8)에서 \(I(X;\tilde{X})\)가 작으면 압축이 강하다는 뜻이고 (cluster 하나면 0), \(I(\tilde{X};Y)\)가 크면 cluster가 여전히 각 조각이 어떤 task에 중요한지 알려 준다는 뜻입니다. \(\beta\)는 둘 사이의 교환 비율을 정합니다.
@@ 43
Clio는 이 문제를 greedy하게 풉니다 (Agglomerative Information Bottleneck). 모든 primitive가 각자 cluster로 시작하고, 이웃끼리 연결되며, 가중치가 가장 작은 쌍을 계속해서 병합합니다: <span class="src">§17.3.4 · p. 513</span>
@@ 44
\(D_{\mathrm{JS}}\)는 Jensen–Shannon divergence입니다. \(\pi_i = p(\tilde{x}_i)/(p(\tilde{x}_i) + p(\tilde{x}_j))\), \(\pi_j = 1 - \pi_i\), 그리고 혼합 분포 \(\bar{p} = \pi_i\, p(y \mid \tilde{x}_i) + \pi_j\, p(y \mid \tilde{x}_j)\)에 대해
@@ 45
병합한 cluster의 확률은 \(p(\tilde{x}_i) + p(\tilde{x}_j)\), task 분포는 \(\bar{p}\)이며, \(d_{ij}\)는 정확히 \(I(\tilde{X};Y)\)의 감소량입니다.
@@ 46
<strong>숫자로 보기.</strong> cluster 두 개가 각각 \(p = 1/12\)입니다. \(p(y \mid x)\)가 같으면 \(D_{\mathrm{JS}} = 0\)이므로 병합은 공짜입니다. 분포가 \((1, 0)\)과 \((0, 1)\)이면 \(\bar{p} = (\tfrac12, \tfrac12)\)이고 각 KL 항은 \(\log 2\)이므로, \(d = \tfrac{2}{12} \times 0.693 = 0.116\) nats입니다.
@@ 47
