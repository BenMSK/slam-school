The mathematics of Days 1–4 becomes software only after two practical problems are solved. First, formulas that are correct on paper can produce 0/0 or lose all their digits in floating point, and AutoDiff faithfully differentiates the bad formula. Second, SLAM needs second-order, robust, manifold-aware optimizers, which deep-learning toolkits do not provide. The libraries of this section exist to close those two gaps.

Now put the corrected quantities of (4.46) into the plain right-hand side of (4.43): \((\mathbf{J}_i^{\rho})\T\boldsymbol{\Sigma}_i\mathbf{r}_i^{\rho} = \rho'(c_i)\,\mathbf{J}_i\T\boldsymbol{\Sigma}_i\mathbf{r}_i\). It is the true gradient (up to the common factor 2). So the corrected problem is an ordinary weighted least-squares problem that has the same gradient as the robust cost at the current estimate. The matrix on the left becomes \(\rho'(c_i)\,\mathbf{J}_i\T\boldsymbol{\Sigma}_i\mathbf{J}_i\), which is positive semidefinite because \(\rho' \ge 0\).
@@ 44
This is iteratively reweighted least squares (<a href="#d34">Week 6 · Day 4</a>) with weight \(\rho'(c_i)\), recomputed at every iteration. The exact Hessian of \(\rho(c_i)\) has one more term, proportional to \(\rho''(c_i)\). For a robust kernel \(\rho\) flattens out, so \(\rho'' \lt 0\), and that term can make the matrix indefinite. Triggs' correction keeps a version of that term; the first-order correction drops it.
@@ 45
<strong>Numbers.</strong> Take the Cauchy kernel \(\rho(c) = \log(1 + c)\), so \(\rho'(c) = 1/(1+c)\), with scalar residuals and \(\Sigma = 1\). An inlier \(r = 0.5\): \(c = 0.25\), \(\rho' = 0.8\), corrected residual \(0.894\times 0.5 = 0.447\). An outlier \(r = 3\): \(c = 9\), \(\rho' = 0.1\), corrected residual \(0.316\times 3 = 0.949\). A residual six times larger enters the solver only about twice as large.

@@ 98
§4.5 then sketches the research landscape. <span class="src">§4.5 · p. 118</span> End-to-end learned odometry comes in supervised forms (DeepVO, TartanVO), which do better but need ground truth that is laborious to collect, and unsupervised forms (UnDeepVO, Unsupervised VIO). Hybrid systems attach geometry to a network: a bundle adjustment layer (BA-Net, DROID-SLAM), a pose and code graph optimized at inference (DeepFactors), a cheirality layer (DiffPoseNet). The book's criticism is that in these systems the pose error is backpropagated <em>through</em> BA while the supervision still comes from ground-truth poses, so BA acts as one more layer. iSLAM instead connects front-end and back-end in both directions as a bilevel problem, so the front-end learns from the result of geometric optimization without external supervision. The same bilevel pattern appears in reinforcement learning, local and global planning, feature matching, and multi-robot routing.
