1. M-estimation and the influence function
@@ 12
Front-end rejection misses some outliers, so the back-end must tolerate them. <span class="src">§3.3 · p. 85</span> <strong>M-estimation</strong> ("maximum-likelihood-type estimation") keeps the residuals \(r_i(\mathbf{x})\) of Day 1 and changes only what is done to them:
@@ 13
The <strong>robust loss</strong> \(\rho\) must be non-negative and grow less than quadratically for large residuals. <span class="src">§3.3 · p. 86</span> To see why that is the right requirement, take the gradient of the cost \(f(\mathbf{x}) = \sum_i \rho(r_i(\mathbf{x}))\) with the chain rule:
@@ 14
The second factor says in which direction measurement \(i\) wants to move the estimate. The first factor says how hard it pulls. That factor is the <strong>influence function</strong> \(\psi(r) := \partial\rho(r)/\partial r\). <span class="src">§3.3 · p. 86</span> For the quadratic loss \(\psi(r) = 2r\): the pull grows without bound, which is Day 1's problem restated. A robust loss has \(\psi(r) \ll 2r\) for large \(r\), and ideally \(\psi(r)\to 0\).

How to choose: <span class="src">§3.3 · pp. 86–87</span>
@@ 35
<strong>Huber</strong> is convex, so the optimization behaves well. It is common in bundle adjustment. The price is the non-zero influence you just saw.
@@ 36
Losses that go flat (Geman-McClure, Tukey, truncated quadratic) give distant outliers little or no influence, but they are non-convex, so the optimizer can stop in a bad local minimum.
@@ 37
A hard cut-off (truncated quadratic) suits problems where the largest error an inlier can have is known.
@@ 38
The <strong>maximum consensus loss</strong>, 0 for small residuals and 1 for large ones, simply counts outliers. Minimizing it is consensus maximization (3.4) from Day 2. Its influence is zero everywhere, so gradients are useless and it is optimized by sampling: that is RANSAC.
@@ 39
Going deeper (optional): a robust loss is still MAP
@@ 40
Switching to \(\rho\) does not abandon probability. A loss is the negative log of a noise density, and losses that grow slowly correspond to heavy-tailed densities. <span class="src">§3.3 · pp. 88–89</span> Take the density proportional to \(\max\{e^{-r^2},\ e^{-\beta^2}\}\): Gaussian near zero, a constant floor (a uniform density over the sensor's range) far away. Its negative log is \(\min\{r^2, \beta^2\}\), the truncated quadratic. The floor says "with some small probability this measurement is unrelated to the state".

@@ 42

Compare with (3.10), \(\sum_i \psi(r_i)\,\partial r_i/\partial\mathbf{x}\). The two sums agree term by term if \(2\,w_i\,r_i = \psi(r_i)\), that is \(w_i = \psi(r_i)/(2r_i)\). That is (3.12).
@@ 47
Now suppose the iteration has converged: \(\mathbf{x}^{(t+1)} = \mathbf{x}^{(t)} = \mathbf{x}^\star\). Then \(\mathbf{x}^\star\) minimizes the weighted problem built with its own weights, so the weighted gradient is zero at \(\mathbf{x}^\star\). By the matching, the gradient (3.10) of the robust cost is zero there too. A fixed point of IRLS is a stationary point of the M-estimation problem. For a non-convex \(\rho\) it may be a poor local minimum, which is tomorrow's topic.

4. Black-Rangarajan duality: weights as variables
@@ 61
Rule (3.12) was obtained by matching gradients, and it is undefined where \(\rho\) has a corner, such as \(|r| = \beta\) for the truncated quadratic. <strong>Black-Rangarajan (B-R) duality</strong> gives the same algorithm a cleaner footing by making the weights unknowns of the optimization. <span class="src">§3.3.2 · p. 90</span>

<strong>Truncated quadratic.</strong> The expression in (3.14) is linear in \(w_i\): it equals \(\beta_i^2 + w_i\,(r_i^2 - \beta_i^2)\). A linear function on \([0,1]\) is smallest at an end. If \(r_i^2 \lt \beta_i^2\) the slope is negative, so \(w_i = 1\) and the value is \(r_i^2\). If \(r_i^2 \gt \beta_i^2\) the slope is positive, so \(w_i = 0\) and the value is \(\beta_i^2\). Either way the result is \(\min\{r_i^2, \beta_i^2\}\). Example: \(r = 3,\ \beta = 2\) gives \(4 + 5w\), minimized at \(w = 0\) with value 4.

@@ 73
<strong>"A robust loss removes outliers."</strong> It reduces their influence. With Huber the influence never reaches zero, as the worked example shows.
@@ 74
<strong>"The IRLS weights are tuning parameters."</strong> They are computed from the residuals by \(w = \psi(r)/(2r)\). The only parameter is \(\beta\).
@@ 75
<strong>"IRLS finds the minimum of the robust cost."</strong> It finds a stationary point that depends on where it starts. The widget's truncated-quadratic run stops at a cost of 8.04, while the line next to the true one costs about 4.3 under the same loss.

Q1. With the Huber loss and β = 1, what IRLS weight does a measurement with residual r = 4 receive?
@@ 77
Beyond β the weight is β/|r| = 1/4. Check with w = ψ/(2r): ψ = 2β = 2, and 2/(2 × 4) = 0.25.
@@ 78
Q2. For the Geman-McClure loss with β = 2, what are the loss and the weight at r = 2?
@@ 79
ρ = β²r²/(β² + r²) = 16/8 = 2, half of the quadratic loss r² = 4. The weight is (β²/(β² + r²))² = (4/8)² = 0.25.
@@ 80
Q3. One IRLS iteration with the truncated quadratic loss, β = 3.5, on the scalar data z = {0, 1, 2, 9}, starting from the mean x = 3. What is the new estimate?
@@ 81
Residuals z − x are −3, −2, −1, 6. Those with |r| below 3.5 get weight 1 and the last gets 0. The weighted mean is (0 + 1 + 2)/3 = 1.0.
@@ 82
Q4. Which loss leaves an outlier with a pull that does not shrink as its residual grows?
@@ 83
Huber's influence is constant at ±2β beyond β. Geman-McClure's decays toward zero, and the other two are exactly zero beyond β. Huber accepts this in exchange for convexity.
