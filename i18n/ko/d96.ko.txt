IMU는 몸체의 회전 속도와 specific force(가속도에서 gravity를 뺀 값)를 body 축 기준으로 내놓으며, 각각에는 천천히 drift하는 bias와 white noise가 있습니다. 가만히 서 있으면 specific force가 위를 향하므로 roll과 pitch는 정해지지만 yaw는 정해지지 않습니다. 측정값을 적분하면 회전, 속도, 위치를 얻지만 오차가 빠르게 자랍니다. accelerometer bias에 대해서는 시간의 제곱으로, gyroscope bias에 대해서는 세제곱으로 자라는데, 기울기 오차가 gravity를 수평 가속도로 새어 들게 하기 때문입니다. 샘플마다 state를 두지 않고 factor graph에서 IMU를 쓰기 위해, 두 keyframe 사이의 적분을 시작 state에도 gravity에도 의존하지 않는 increment로 재배열합니다. increment는 한 번 적분하고, bias 추정값이 움직이면 1차로 보정하며, 9차원 factor 하나와 bias random-walk factor 하나로 graph에 들어갑니다.

@@ 60

@@ 67
\(\tfrac16 g\,b_g t^3 = \tfrac12 b_a t^2\)로 놓으면 \(t = 3b_a/(g\,b_g)\)입니다. \(b_g = 0.01^\circ/\text{s} = 1.745\times10^{-4}\) rad/s이면 \(t = 0.06/(9.81\times1.745\times10^{-4}) = 35.0\) s입니다.

손으로 하는 1-D preintegration. 센서가 회전하지 않고 수직축을 따라 움직입니다. z가 위, \(g = -9.81\) m/s²입니다. \(\Delta t = 0.1\) s 간격의 accelerometer 샘플 세 개가 10.81, 9.81, 8.81 m/s²이고 bias는 0입니다. (a) \(\Delta v_{ij}\)와 \(\Delta p_{ij}\)를 계산하세요. (b) \(v_i = 1\) m/s, \(p_i = 0\)에 대해 \(v_j\)와 \(p_j\)를 예측하고, (11.12)로 직접 적분해 확인하세요. (c) solver가 \(v_i\)를 1.5 m/s로 바꿉니다. 이제 \(p_j\)는 얼마입니까? (d) accelerometer bias 추정값이 0에서 0.1 m/s²로 바뀝니다. \(\Delta v_{ij}\)와 \(\Delta p_{ij}\)를 1차로 보정하고 재적분 결과와 비교하세요.
@@ 70
(a) 회전이 없으므로 \(\Delta R = 1\). \(\Delta v_{ij} = (10.81 + 9.81 + 8.81)\times0.1 = 2.943\) m/s. \(\Delta p_{ij} = \sum_k[\Delta v_{ik}\Delta t + \tfrac12\tilde a_k\Delta t^2]\)에서 누적 \(\Delta v_{ik}\)는 0, 1.081, 2.062입니다.
@@ 71
\(k=0\): \(0 + 0.05405\); \(k=1\): \(0.1081 + 0.04905\); \(k=2\): \(0.2062 + 0.04405\). 합: \(\Delta p_{ij} = 0.46145\) m.
@@ 72
직접 적분: 실제 가속도는 \(\tilde a + g = 1, 0, -1\)입니다. 속도: 1 → 1.1 → 1.1 → 1.0. 위치: \(0.1 + 0.005 = 0.105\); \(+0.11 = 0.215\); \(+0.11 - 0.005 = 0.32\). 두 결과가 일치합니다.
@@ 73
(c) \(v_i\Delta t_{ij}\) 항만 바뀝니다: \(p_j = 0.45 - 0.44145 + 0.46145 = 0.47\) m. 샘플은 하나도 건드리지 않습니다.
@@ 74
(d) 회전이 없으면 Jacobian은 \(\partial\Delta v/\partial b^a = -\Delta t_{ij} = -0.3\) s, \(\partial\Delta p/\partial b^a = -\tfrac12\Delta t_{ij}^2 = -0.045\) s²입니다. 보정 결과: \(\Delta v_{ij} = 2.943 - 0.03 = 2.913\) m/s, \(\Delta p_{ij} = 0.46145 - 0.0045 = 0.45695\) m. 샘플 10.71, 9.71, 8.71로 재적분하면 \(\Delta v = 2.913\), \(\Delta p = 0.05355 + (0.1071 + 0.04855) + (0.2042 + 0.04355) = 0.45695\)로, 계산식이 accelerometer bias에 대해 선형이므로 똑같습니다.
