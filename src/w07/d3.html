Implicit differentiation: the gradient from the optimality condition

After today you can derive the sensitivity of the back-end solution from its optimality condition, compute the upper-level gradient with one linear solve built from Hessian-vector products, and choose between unrolled and implicit differentiation.

Today's big idea

At the solution the gradient of the lower-level cost is zero, for every \(\mathbf{y}\). Differentiating that one equation gives \(\partial\mathbf{x}^*/\partial\mathbf{y}\) in terms of second derivatives of \(\mathcal{L}\) at the solution only. How the solver got there does not matter, nothing has to be stored along the way, and the whole upper-level gradient costs one linear solve with the Hessian.

1. A derivative without a formula

Some functions are defined by an equation, not by an explicit formula. The book's reminder uses \(x + y + 5 = 0\). §4.2.3 · p. 107 A less trivial case: let \(x(y)\) be defined by

\[ F(x, y) = x^3 + x - y = 0 . \]

For each \(y\) there is one real \(x\), but no pleasant formula for it. Differentiate the equation itself with respect to \(y\), remembering that \(x\) depends on \(y\):

\[ 3x^2\,\frac{dx}{dy} + \frac{dx}{dy} - 1 = 0 \quad\Longrightarrow\quad \frac{dx}{dy} = \frac{1}{3x^2 + 1} . \]

At \(y = 2\) the solution is \(x = 1\) (check: \(1 + 1 - 2 = 0\)), so \(dx/dy = 1/4\). We needed the point on the curve, found any way we like, and derivatives of \(F\) at that point. This is implicit differentiation.

Filling the gap: the implicit function theorem

The step "remembering that \(x\) depends on \(y\)" assumes a differentiable function \(x(y)\) exists. The implicit function theorem says when. Let \(F:\R^n\times\R^m\to\R^n\) be continuously differentiable with \(F(\mathbf{x}_0,\mathbf{y}_0) = \mathbf{0}\). If the \(n\times n\) matrix \(\partial F/\partial\mathbf{x}\) is invertible at \((\mathbf{x}_0,\mathbf{y}_0)\), then near \(\mathbf{y}_0\) there is exactly one continuously differentiable function \(\mathbf{x}(\mathbf{y})\) with \(\mathbf{x}(\mathbf{y}_0)=\mathbf{x}_0\) and \(F(\mathbf{x}(\mathbf{y}),\mathbf{y}) = \mathbf{0}\), and

\[ \frac{\partial\mathbf{x}}{\partial\mathbf{y}} = -\left(\frac{\partial F}{\partial\mathbf{x}}\right)^{-1}\frac{\partial F}{\partial\mathbf{y}} . \]

The formula is what you get by differentiating \(F(\mathbf{x}(\mathbf{y}),\mathbf{y}) = \mathbf{0}\) with the chain rule, \(\frac{\partial F}{\partial\mathbf{x}}\frac{\partial\mathbf{x}}{\partial\mathbf{y}} + \frac{\partial F}{\partial\mathbf{y}} = \mathbf{0}\), and solving. The theorem is local: it describes the solution branch through \((\mathbf{x}_0,\mathbf{y}_0)\), nothing more.

2. Apply it to the optimality condition

Which equation defines \(\mathbf{x}^*(\mathbf{y})\)? The lower-level solution is a stationary point of \(\mathcal{L}\), so (assuming \(\mathcal{L}\) is twice differentiable in both arguments) §4.2.3 · p. 107

\[ \frac{\partial\mathcal{L}(\mathbf{x}^*(\mathbf{y}),\mathbf{y})}{\partial\mathbf{x}^*(\mathbf{y})} = \mathbf{0} \qquad\text{for every } \mathbf{y}. \]

Take \(F = \partial\mathcal{L}/\partial\mathbf{x}\) in the theorem. Differentiating both sides with respect to \(\mathbf{y}\) gives

\[ \frac{\partial^2\mathcal{L}(\mathbf{x}^*(\mathbf{y}),\mathbf{y})}{\partial\mathbf{x}^*(\mathbf{y})\,\partial\mathbf{y}} + \frac{\partial^2\mathcal{L}(\mathbf{x}^*(\mathbf{y}),\mathbf{y})}{\partial\mathbf{x}^*(\mathbf{y})\,\partial\mathbf{x}^*(\mathbf{y})}\cdot\frac{\partial\mathbf{x}^*(\mathbf{y})}{\partial\mathbf{y}} = \mathbf{0}, \tag{4.11} \] \[ \frac{\partial\mathbf{x}^*(\mathbf{y})}{\partial\mathbf{y}} = -\left(\frac{\partial^2\mathcal{L}(\mathbf{x}^*(\mathbf{y}),\mathbf{y})}{\partial\mathbf{x}^*(\mathbf{y})\,\partial\mathbf{x}^*(\mathbf{y})}\right)^{-1}\frac{\partial^2\mathcal{L}(\mathbf{x}^*(\mathbf{y}),\mathbf{y})}{\partial\mathbf{x}^*(\mathbf{y})\,\partial\mathbf{y}} . \tag{4.12} \]

In short: \(\partial\mathbf{x}^*/\partial\mathbf{y} = -\mathbf{H}^{-1}\,\mathbf{H}_{xy}\), where \(\mathbf{H} = \partial^2\mathcal{L}/\partial\mathbf{x}\partial\mathbf{x}\) is the \(n\times n\) Hessian of the lower-level cost and \(\mathbf{H}_{xy} = \partial^2\mathcal{L}/\partial\mathbf{x}\partial\mathbf{y}\) is the \(n\times m\) matrix of mixed second derivatives, both at the solution. The indirect gradient has become direct derivatives of \(\mathcal{L}\), at the cost of inverting a Hessian. §4.2.3 · p. 107

Toy problem. From Day 2: \(\partial^2\mathcal{L}/\partial x^2 = 6x^2 - 2y + 1\) and \(\partial^2\mathcal{L}/\partial x\,\partial y = -2x\). At \(y = 2\), \(x^* = (1+\sqrt3)/2 = 1.3660\):

\[ H = 6(1.8660) - 4 + 1 = 8.196, \qquad \frac{dx^*}{dy} = -\frac{-2(1.3660)}{8.196} = \frac{2.732}{8.196} = \frac13 . \]

That is the 0.333 that two extra solves gave by finite differences on Day 1, and the value the unrolled sensitivities 0.2000, 0.3272, 0.3491 of Day 2 were converging to. It took no extra solve and no stored iterates.

Try it: move y along the curve, then press the upper-level step button repeatedly.

Notice that at y = 2 the tangent slope is 0.3333 and dU/dy = −0.0447. Each upper-level step moves y to the right, toward y ≈ 2.417 where the curve crosses the ground-truth line and U reaches zero. Then press Reset and set the Algorithm 2 step size to 0.30: the iteration for q diverges, because 0.30 is above 2/H = 0.244 (see §4).

Intuition

Picture the lower-level cost as a valley whose floor shifts when \(\mathbf{y}\) changes. \(\mathbf{H}_{xy}\) says how hard a change in \(\mathbf{y}\) pushes the ball sideways (it is the change in the slope \(\partial\mathcal{L}/\partial\mathbf{x}\)). \(\mathbf{H}\) is the stiffness of the valley. Displacement = push divided by stiffness: a stiff, well-constrained SLAM problem moves little when a measurement changes; a floppy one moves a lot.

The theorem's condition matters: \(\mathbf{H}\) must be invertible. At a strict minimum it is positive definite, so this holds. If the lower-level problem has directions that the measurements do not constrain at all, \(\mathbf{H}\) is singular, the minimizer is not unique, and "the derivative of the solution" has no meaning until those directions are fixed.

3. Never build the big matrices

Substitute (4.12) into the gradient (4.3): §4.2.3 · p. 107

\[ \nabla_{\mathbf{y}}\,\mathcal{U} = \frac{\partial\,\mathcal{U}(\mathbf{y},\mathbf{x}^*)}{\partial\mathbf{y}} - \underbrace{\frac{\partial\,\mathcal{U}(\mathbf{y},\mathbf{x}^*)}{\partial\mathbf{x}^*}}_{\mathbf{v}\T}\; \underbrace{\left(\frac{\partial^2\mathcal{L}}{\partial\mathbf{x}^*\partial\mathbf{x}^*}\right)^{-1}}_{(\mathbf{H}\T)^{-1}}\; \frac{\partial^2\mathcal{L}}{\partial\mathbf{x}^*\partial\mathbf{y}} = \frac{\partial\,\mathcal{U}(\mathbf{y},\mathbf{x}^*)}{\partial\mathbf{y}} - \mathbf{q}\T\cdot\frac{\partial^2\mathcal{L}}{\partial\mathbf{x}^*\partial\mathbf{y}} . \tag{4.13} \]

The product of three factors can be grouped in two ways, and the choice decides the cost.

So define \(\mathbf{q}\) as the solution of \(\mathbf{H}\mathbf{q} = \mathbf{v}\), with \(\mathbf{v} = (\partial\mathcal{U}/\partial\mathbf{x}^*)\T\). (The Hessian is symmetric, so \(\mathbf{H}\T = \mathbf{H}\).) This is the same trick as reverse mode on Day 1: push the single output's sensitivity backward instead of pushing every parameter's influence forward. The vector \(\mathbf{q}\) is called the adjoint, and the procedure the adjoint method.

Even one solve can be too much if \(\mathbf{H}\) must be stored. In Example 4.3, a model with \(10^6\) parameters as 32-bit floats takes \(10^6\times 4\) bytes \(= 4\) MB, and its Hessian \((10^6)^2\times 4\) bytes \(= 4\) TB. Example 4.3 · p. 107 The way out is to solve \(\mathbf{H}\mathbf{q}=\mathbf{v}\) with a method that only ever asks for products \(\mathbf{H}\mathbf{q}\).

4. Solving Hq = v with Hessian-vector products

The book turns the linear system into a minimization, §4.2.3 · p. 108

\[ \mathbf{q}^* = \argmin_{\mathbf{q}}\; Q(\mathbf{q}) = \argmin_{\mathbf{q}}\; \tfrac12\,\mathbf{q}\T\mathbf{H}\mathbf{q} - \mathbf{q}\T\mathbf{v}, \tag{4.14} \]

and solves it by gradient descent (Algorithm 2) or conjugate gradient:

\[ \mathbf{q}_k = \mathbf{q}_{k-1} - \eta\,(\mathbf{H}\mathbf{q}_{k-1} - \mathbf{v}) . \tag{4.16} \]

The product \(\mathbf{H}\mathbf{q}\) is computed without \(\mathbf{H}\), as "the gradient of a gradient-vector product":

\[ \mathbf{H}\mathbf{q} = \frac{\partial^2\mathcal{L}}{\partial\mathbf{x}\,\partial\mathbf{x}}\cdot\mathbf{q} = \frac{\partial\left(\frac{\partial\mathcal{L}}{\partial\mathbf{x}}\cdot\mathbf{q}\right)}{\partial\mathbf{x}} . \tag{4.15} \]

Finally \(\nabla_{\mathbf{y}}\,\mathcal{U} = \partial\mathcal{U}/\partial\mathbf{y} - (\mathbf{H}_{yx}\,\mathbf{q})\T\) with \(\mathbf{H}_{yx} = \partial^2\mathcal{L}/\partial\mathbf{y}\,\partial\mathbf{x}^* = \mathbf{H}_{xy}\T\), equation (4.17), which is one more product of the same kind.

Filling the gap: three steps the book states without proof

Why minimizing Q solves the system. \(\partial Q/\partial\mathbf{q} = \mathbf{H}\mathbf{q} - \mathbf{v}\) (using the symmetry of \(\mathbf{H}\)). At a minimum the gradient is zero, so \(\mathbf{H}\mathbf{q} = \mathbf{v}\). With \(\mathbf{H}\) positive definite, \(Q\) is a bowl with exactly one minimum.

Why (4.15) holds. Hold \(\mathbf{q}\) constant. The scalar \(s(\mathbf{x}) = \frac{\partial\mathcal{L}}{\partial\mathbf{x}}\cdot\mathbf{q} = \sum_j \frac{\partial\mathcal{L}}{\partial x_j}q_j\) has \(i\)-th partial derivative \(\sum_j \frac{\partial^2\mathcal{L}}{\partial x_i\partial x_j}q_j\), which is the \(i\)-th entry of \(\mathbf{H}\mathbf{q}\). In practice: one reverse pass for the gradient, a dot product with \(\mathbf{q}\), and one more reverse pass through that computation. The cost is a small multiple of one gradient, and the memory is that of vectors.

When (4.16) converges. Subtract the exact solution \(\mathbf{q}^*\): the error obeys \(\mathbf{q}_k - \mathbf{q}^* = (\mathbf{I} - \eta\mathbf{H})(\mathbf{q}_{k-1} - \mathbf{q}^*)\). Along an eigenvector of \(\mathbf{H}\) with eigenvalue \(\lambda\) the error is multiplied by \(1 - \eta\lambda\) each step, so it shrinks if and only if \(|1-\eta\lambda| \lt 1\) for every eigenvalue, that is \(0 \lt \eta \lt 2/\lambda_{\max}\). If the eigenvalues are spread widely (an ill-conditioned Hessian), the small ones converge slowly; conjugate gradient copes with that much better.

Toy numbers. \(v = x^* - 1.5 = -0.1340\), \(H = 8.196\), \(\eta = 0.1\), \(q_0 = 0\):

\[ q_1 = -0.0134, \quad q_2 = -0.0158, \quad q_3 = -0.0163, \;\dots\;\to\; \frac{v}{H} = -0.01635 . \]

The error shrinks by the factor \(|1 - 0.1\times 8.196| = 0.18\) per step. Then \(\nabla_y\,\mathcal{U} = 0 - q\,H_{xy} = -(-0.01635)(-2.732) = -0.0447\).

Going deeper (optional): what a SLAM back-end already has

For a least-squares cost \(\mathcal{L} = \tfrac12\norm{\mathbf{r}}^2\) the Hessian is \(\mathbf{J}\T\mathbf{J}\) plus a term that multiplies the residuals by their second derivatives. Gauss-Newton drops the second term. A back-end that has just converged holds \(\mathbf{J}\T\mathbf{J}\) and usually a factorization of it, so an approximate adjoint solve \(\mathbf{J}\T\mathbf{J}\,\mathbf{q} = \mathbf{v}\) is nearly free. In the toy problem \(\mathbf{J}\T\mathbf{J} = 4x^{*2}+1 = 8.464\) against the exact \(H = 8.196\); the slope would come out as \(2.732/8.464 = 0.323\) where the exact value is 0.333. The approximation is good when the residuals at the solution are small.

Algorithm 1 on p. 105 applies the implicit formula at \(\mathbf{x}_T\), the iterate the solver actually returned. The widget from Day 2 shows what that does when \(T\) is small:

Notice the violet curve, the implicit formula evaluated at x_K (its values at K = 0 and 1 are far below the chart; the tile shows them). At K = 2 it reads −0.0662, further from the reference −0.0447 than the unrolled value −0.0607, because x₂ is not a stationary point and the formula's assumption fails. Once the inner solver has converged the two coincide.

Approximations. The cheapest option of all ignores the implicit part and keeps only the direct term, \(\hat\nabla_{\mathbf{y}}\,\mathcal{U} \approx \partial\mathcal{U}/\partial\mathbf{y}\,|_{\mathbf{x}_T}\). It treats the solver's output as a constant in the upper-level problem. The error is of the size of the dropped term, §4.2.3 · p. 108

\[ \epsilon \sim \left|\frac{\partial\,\mathcal{U}}{\partial\mathbf{x}^*}\,\frac{\partial\mathbf{x}^*}{\partial\mathbf{y}}\right| . \tag{4.18} \]

The book notes it is useful when the implicit part contains products of small second-order derivatives. It is useless when \(\mathcal{U}\) has no direct dependence on \(\mathbf{y}\): in the toy problem it returns exactly zero.

Common mistakes

  • "Implicit differentiation needs the inverse Hessian." It needs the solution of one linear system \(\mathbf{H}\mathbf{q}=\mathbf{v}\), and that needs only products \(\mathbf{H}\mathbf{q}\).
  • "It is exact, so it is safe to stop the inner solver early." It is exact at a stationary point. Evaluated elsewhere it is the derivative of nothing in particular.
  • "The mixed term has the same sign convention as the Hessian." Watch the minus sign in (4.12). In the toy problem \(H_{xy} = -2x\) is negative and the slope \(dx^*/dy\) is positive.

Check yourself

Q1. Let L(x, y) = ½(x − y)² + (3/2)x². Use (4.12) to find dx*/dy.

∂L/∂x = (x − y) + 3x, so H = 4 and ∂²L/∂x∂y = −1. dx*/dy = −(1/4)(−1) = 1/4. Check: the minimizer is x* = y/4.

Q2. In the toy problem at y = 1 the solution is x* = 1. What is dx*/dy there?

H = 6x² − 2y + 1 = 6 − 2 + 1 = 5 and ∂²L/∂x∂y = −2x = −2, so dx*/dy = 2/5 = 0.4.

Q3. Algorithm 2 runs on a scalar problem with H = 4. Which step size makes the iteration diverge?

The error is multiplied by 1 − ηH each step: 0.6, 0, −0.6, −1.4. Only |−1.4| exceeds 1. The limit is η = 2/H = 0.5.

Q4. With n = 600 back-end variables and m = 1,000,000 network weights, why solve Hq = v rather than first computing ∂x*/∂y = −H⁻¹·∂²L/∂x∂y?

Both groupings give the same gradient. Solving for q costs one linear solve; forming ∂x*/∂y costs one per parameter and stores a 600 × 1,000,000 dense matrix.

Q5. A lower-level problem has n = 100,000 variables. How much memory would its dense Hessian take in 8-byte floats?

(10⁵)² × 8 bytes = 8 × 10¹⁰ bytes = 80 GB. The vector itself takes 0.8 MB. This is Example 4.3 with other numbers.

Recap

  1. The solution satisfies \(\partial\mathcal{L}/\partial\mathbf{x} = \mathbf{0}\) for every \(\mathbf{y}\); differentiating this gives \(\partial\mathbf{x}^*/\partial\mathbf{y} = -\mathbf{H}^{-1}\mathbf{H}_{xy}\), equation (4.12).
  2. The implicit function theorem justifies the step and requires \(\mathbf{H}\) to be invertible.
  3. The upper-level gradient needs only \(\mathbf{q} = \mathbf{H}^{-1}\mathbf{v}\): one adjoint solve, equation (4.13).
  4. The solve uses Hessian-vector products (4.15), so \(\mathbf{H}\) is never formed; gradient descent on \(Q\) converges for \(\eta \lt 2/\lambda_{\max}\).
  5. Implicit differentiation is memory-free in the number of solver steps but assumes convergence; unrolling is the reverse.
