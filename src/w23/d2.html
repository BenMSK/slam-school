Today's big idea

Open-world mapping uses three kinds of pretrained model. A feature-based model turns an image or a text into a vector, and everything is done by comparing vectors. A generative model produces new text from a prompt. A class-agnostic segmenter cuts an image into object-shaped regions without naming them. Tomorrow's maps are built by combining the three.

1. A feature is a vector, and similarity is an angle

A feature (also called an embedding, representation, or code) is the real-valued vector a deep network outputs for one input. The book hides the network behind a function: an encoder \(f_{\mathcal{X}}\) for inputs of modality \(\mathcal{X}\) (text, image, sound) maps an input \(x\) to a \(d\)-dimensional feature \(\mathbf{f}_x = f_{\mathcal{X}}(x) \in \R^d\). The property that matters is that distances in feature space measure meaningful similarity, so that "how similar is this caption to this image?" becomes a calculation. §17.2.1 · p. 496

The standard measure is cosine similarity, the cosine of the angle between two features drawn as arrows from the origin: §17.2.1 · p. 496

\[ \cos\theta = \frac{\langle \mathbf{a}, \mathbf{b} \rangle}{\norm{\mathbf{a}}\,\norm{\mathbf{b}}}, \qquad \langle \mathbf{a}, \mathbf{b} \rangle = \sum_{i=1}^{d} a_i b_i . \]

Numbers. \(\mathbf{a} = (3, 4)\), \(\mathbf{b} = (4, 3)\): \(\langle \mathbf{a}, \mathbf{b} \rangle = 12 + 12 = 24\), both norms are 5, so \(\cos\theta = 24/25 = 0.96\), an angle of about 16°. It ranges from 1 (same direction) through 0 (perpendicular, unrelated) to −1 (opposite), and ignores length.

Filling the gap: unit vectors, dot products, and distances

CLIP outputs unit-norm features, \(\norm{\mathbf{f}} = 1\). §17.2.1 · p. 497 Then the denominator above is 1 and cosine similarity is just the inner product \(\langle \mathbf{a}, \mathbf{b} \rangle\). That is why every formula in this chapter is written with \(\langle \cdot, \cdot \rangle\).

For unit vectors, "close in angle" and "close in distance" are the same statement. Expand the squared distance:

\[ \norm{\mathbf{a} - \mathbf{b}}^2 = \norm{\mathbf{a}}^2 - 2\langle \mathbf{a}, \mathbf{b} \rangle + \norm{\mathbf{b}}^2 = 2 - 2\langle \mathbf{a}, \mathbf{b} \rangle . \]

Check with the example: \(\mathbf{a}/5 = (0.6, 0.8)\), \(\mathbf{b}/5 = (0.8, 0.6)\), difference \((-0.2, 0.2)\), squared length \(0.08 = 2 - 2 \times 0.96\). So ranking by largest cosine and ranking by smallest Euclidean distance give the same order. Vectors that are not unit length (after averaging, as tomorrow) must be divided by their norm first.

§17.2.1 · pp. 496–497 DINO's features serve vision tasks directly: nearest neighbours in its feature space classify or retrieve images. But DINO has no text encoder, so you cannot type a word at it. CLIP's defining property is the aligned feature space: two encoders, trained so that an image and its caption land close together (yesterday's loss).

How many patch features is that? For a 224×224 image and 8×8 patches (our example sizes), \(224/8 = 28\) patches per side, so \(28 \times 28 = 784\) vectors instead of one. One warning the book gives: you can pull patch-level features out of CLIP's image encoder too, but you should not expect them to be language-aligned, and studies have found them weaker than DINO's for vision and 3D tasks. §17.2.1 · p. 497

3. A classifier made of sentences

With aligned features, a classifier needs no training. Write each class as text, possibly in a template ("a picture of a dog", "a picture of a cat"), encode each prompt to get \(\mathbf{f}_c\), and predict

\[ \argmax_{c \in \mathsf{C}} \; \langle \mathbf{f}_I, \mathbf{f}_c \rangle . \tag{17.1} \]

This is a zero-shot classifier: it never saw a labeled example of these classes. Changing the problem means changing the list \(\mathsf{C}\). §17.2.1 · p. 497

Try it: the image is an armchair and the class set has no "chair". Add "chair". Then choose the soda can and see what the classifier says before and after you add "drink".

Notice that with {sofa, television, plant} the armchair is called a sofa (0.95), and adding "chair" (0.99) flips the answer with no retraining. The soda can scores 0.00 against all three starting classes, yet arg max still returns one of them: a class set is a closed set, however you obtained the classifier.

4. Generative models: one token at a time

A large language model (LLM) is a transformer trained to generate text. Text is first cut into tokens (words, sub-words, characters, or bytes from a fixed vocabulary), each with a learnable embedding. The training objective is next-token prediction: given the first \(T-1\) tokens, output the probabilities \(p(w_T \mid w_{1:T-1})\) of the next one. §17.2.2 · p. 498

Filling the gap: why predicting one token is enough to write paragraphs

The chain rule of probability factors any joint distribution into next-item conditionals:

\[ p(w_1, \dots, w_T) = \prod_{t=1}^{T} p(w_t \mid w_{1:t-1}) . \]

So a model of the next token is a model of whole texts. Generation runs the factorization forward, which the book calls autoregressive:

context = tokens(prompt)
repeat:
    probs = model(context)        # p(next token | context)
    w     = choose_from(probs)
    context.append(w)
until w is a stop token or a length limit is hit

Each new token costs one pass through a very large network. Compare CLIP: one pass per image, then dot products. This is the book's remark that generative inference "tends to be more computationally expensive than extracting features". §17.2 · p. 495

An LLM can be applied to any task whose instructions, inputs, and outputs fit in text, and the wording of the prompt matters. The book names two prompt techniques: chain-of-thought (ask the model to reason step by step) and in-context learning (put input–output examples in the prompt). §17.2.2 · p. 498 A vision language model (VLM) is an LLM that also accepts image tokens. The book's example, LLaVA, connects the CLIP vision encoder to an LLM and trains on vision-and-language data. Given the right prompt a VLM can classify, caption, or answer questions about an image. §17.2.2 · p. 499 As of the book's April 2026 edition it lists the LLaMa family and the GPT models as widely used, and notes that newer models appear frequently.

5. Masks without names

The third tool answers "which pixels belong together?" For an RGB image \(\mathbf{I}\) of width \(W\) and height \(H\), a segmenter returns a set of binary masks \(\mathbf{Z}_i \in \{0,1\}^{H \times W}\), one per likely object: \(\mathbf{Z}_i[u,v] = 1\) where pixel \((u,v)\) belongs to region \(i\). The book writes this function \(\texttt{Seg}(\cdot)\). The masks must be class-agnostic, meaning proposed without any class list, or the segmenter would bring the closed set back in. §17.2.3 · p. 499

The main tool is the Segment Anything Model (SAM). It is promptable: give it pixel coordinates, a bounding box, or another mask, and it predicts a mask. It can also process a whole image and return masks for the instances in it. Unlike the models above, SAM is trained by large-scale supervised learning. It can also refine the boxes of an open-vocabulary detector, which gives better object outlines and shorter inference time. §17.2.3 · p. 499

Common mistakes

  • "CLIP gives a language-aligned feature for every pixel." Its aligned feature describes the whole image. Patch features can be extracted, but the book warns not to expect them to be language-aligned.
  • "A higher dot product always means more similar." Only for unit vectors. Without normalizing, a long vector wins by length alone.

Check yourself

Q1. What is the cosine similarity of a = (1, 2, 2) and b = (2, 1, 2)?

The inner product is 2 + 2 + 4 = 8 and both norms are √9 = 3, so the cosine is 8/9 = 0.89.

Q2. An image has unit feature (0.6, 0.8). The class prompts encode to dog (1, 0), cat (0, 1), fox (0.8, 0.6). What does equation (17.1) predict?

Scores: dog 0.6, cat 0.8, fox 0.48 + 0.48 = 0.96. Arg max picks the largest, whatever its size.

Q3. Two unit features are at squared Euclidean distance 0.5. What is their cosine similarity?

For unit vectors the squared distance is 2 − 2·cos, so cos = (2 − 0.5)/2 = 0.75.

Q4. Why does the book require the segmentation masks to be class-agnostic?

The masks decide which regions get features at all. If only listed classes get masks, everything else never enters the map.

Recap

  1. An encoder maps an input to a feature vector; cosine similarity (the inner product, for unit features) measures how related two inputs are.
  2. DINO gives strong vision-only features, including per-patch ones. CLIP aligns images and text in one space.
  3. Equation (17.1) builds a classifier from text prompts: encode the class names and take the arg max of the similarities.
  4. LLMs generate text by repeated next-token prediction; VLMs also take images. They are more capable and more expensive than feature extraction.
  5. \(\texttt{Seg}(\cdot)\), usually SAM, returns class-agnostic binary masks.
