Week 23 review: open-world maps and foundation models

After today you can compute the contrastive loss, fuse and query feature maps, match masks to objects, and compute a LERF relevancy and a task-driven merge cost by hand.

About 60 min · No new pages

The week in one paragraph

Models trained on internet-scale data without human labels produce features tied to no class list. CLIP's contrastive training puts images and text in one space where similarity is an inner product. An open-vocabulary map stores such features on points, objects, graph nodes, or in a radiance field, fuses them over views by a weighted average, and is questioned afterwards by encoding text and comparing. Captions and LLMs handle complex questions; a task list can decide what an object is. Whether large models will replace explicit maps is open as of the book's April 2026 edition.

2. Mixed quiz

Check yourself

Q1. In a batch of 8 pairs, every image is equally similar to all 8 captions. What is the contrastive loss per image?

Every softmax weight is 1/8, so the loss is log 8.

Q2. Why does §17.1.1 say foundation models are harder to build for LiDAR or radar?

Internet-scale data is a key ingredient, and these modalities lack it.

Q3. An image has unit feature (0.6, 0.8, 0). Prompts encode to A = (1, 0, 0), B = (0, 0.8, 0.6), C = (0, 0, 1). What does (17.1) return?

A: 0.6. B: 0.8 × 0.8 = 0.64. C: 0.

Q4. A language model gives the three tokens of a sentence conditional probabilities 0.5, 0.2, 0.1. What is the probability of the sentence?

The chain rule multiplies them: 0.5 × 0.2 × 0.1 = 0.01.

Q5. A map point has c = 1, f = (1, 0). A view adds (0, 1) with α = 1. After normalizing, what is its similarity to the query (0, 1)?

The fused feature (0.5, 0.5) normalizes to (0.707, 0.707).

Q6. A dense map has 2 million points, each with a 512-number feature of 4-byte numbers. How much memory is that?

2 × 10⁶ × 512 × 4 bytes = 4.1 × 10⁹ bytes.

Q7. In task-driven clustering, a task is added that cares about the individual keys of a piano. What changes?

The cost (17.9) grows with how differently two clusters relate to the tasks.

Q8. Which statement matches the book's position, as of its April 2026 edition?

§17.4.2 says so; §17.4.4 calls maps and generalist policies complementary.

3. Pen-and-paper problems

  1. \(N = 3\), \(\tau = 0.5\). Image 1 has similarities \(0.9\) (own caption), \(0.1\), \(0.5\). Compute its loss and the derivative with respect to each similarity.

    Solution

    \(e^{1.8} = 6.050\), \(e^{0.2} = 1.221\), \(e^{1.0} = 2.718\), sum \(9.989\). Softmax \(p = (0.606, 0.122, 0.272)\), loss \(-\log 0.606 = 0.502\). Derivatives \((p_{1j} - \delta_{1j})/\tau\): \(-0.789\), \(0.244\), \(0.544\).

  2. A map point starts with \(c_k = 0\). View 1 gives \((1, 0, 0)\) at \(\gamma = 0\); view 2 gives \((0.6, 0.8, 0)\) at \(\gamma = \sigma\). Fuse them with (17.2)–(17.3). Does a query with \(\mathbf{f}_T = (0.8, 0.6, 0)\) and threshold 0.9 retrieve the point?

    Solution

    \(\alpha_1 = 1\), \(\alpha_2 = e^{-1/2} = 0.607\). Fused: \(((1,0,0) + 0.607\,(0.6, 0.8, 0))/1.607 = (0.849, 0.302, 0)\), \(c_k = 1.607\). Length \(0.901\), unit feature \((0.942, 0.335, 0)\). Similarity \(0.942 \times 0.8 + 0.335 \times 0.6 = 0.955\): retrieved. Unnormalized it would be \(0.860\) and wrongly rejected.

  3. In one dimension, a mask's points are at \(0.0, 0.1, 0.2, 0.3, 1.0\) m. An object has points at \(0.05, 0.15, 0.25\) m, feature \((0.6, 0.8)\), count 3. The mask's feature is \((1, 0)\) and \(\delta_{nn} = 0.08\) m. Compute \(\phi_{geo}\) and \(\phi_{sim}\); if both exceed 0.5, update the object.

    Solution

    Four mask points are 0.05 m from an object point; the one at 1.0 is 0.75 m away. \(\phi_{geo} = 4/5 = 0.8\). Inner product \(0.6\), so \(\phi_{sim} = 0.8\). Match. \(\mathbf{f}_o \leftarrow (3\,(0.6, 0.8) + (1, 0))/4 = (0.7, 0.6)\), count 4, and the mask points join the cloud.

  4. Primitives A, B, C in a row, each with probability \(1/3\), have \(p(y \mid A) = p(y \mid B) = (0.9, 0.1)\) and \(p(y \mid C) = (0.1, 0.9)\). (a) Compute \(d_{AB}\) and \(d_{BC}\). (b) Merge the cheaper pair and cost the last merge. (c) Check that the costs add up to \(I(X;Y)\).

    Solution

    (a) \(d_{AB} = 0\). For B, C: \(\bar{p} = (0.5, 0.5)\), \(D_{\mathrm{KL}} = 0.9 \log 1.8 + 0.1 \log 0.2 = 0.368\) for each, so \(D_{\mathrm{JS}} = 0.368\), \(d_{BC} = \tfrac23 \times 0.368 = 0.245\) nats.

    (b) AB has probability \(\tfrac23\) and distribution \((0.9, 0.1)\). With C: \(\bar{p} = (0.633, 0.367)\), and the same formula gives \(D_{\mathrm{KL}} = 0.186\) for AB and \(0.624\) for C. \(D_{\mathrm{JS}} = \tfrac23(0.186) + \tfrac13(0.624) = 0.332\), so \(d = 0.332\) nats.

    (c) \(p(y) = (0.633, 0.367) = \bar{p}\), so \(I(X;Y) = \tfrac13(0.186 + 0.186 + 0.624) = 0.332 = 0 + 0.332\).
